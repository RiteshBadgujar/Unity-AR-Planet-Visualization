# 📖 About the Project

**Unity AR Planet Visualization** is an educational Augmented Reality (AR) application developed using **Unity**, **C#**, and **AR Foundation**.

The application detects real-world surfaces using the device camera and allows users to place realistic **3D planetary models** into their surroundings. Users can interact with planets through intuitive touch gestures such as placement, rotation, and zoom, creating an engaging and immersive learning experience.

This project demonstrates practical implementation of modern **mobile AR development**, making astronomy education more interactive and visually appealing.

# 🚀 Key Functionalities

### 📍 AR Plane Detection

Detects horizontal surfaces using AR Foundation for accurate object placement.

---

### 🌍 Planet Placement

Users can tap on detected surfaces to place 3D planets in the real environment.

---

### 🔄 Planet Rotation

Planets can be rotated smoothly using touch gestures.

---

### 🔍 Zoom Interaction

Pinch gestures allow users to scale planets for a closer view.

---

### 🎥 Camera Feed

Displays the real-world environment using the device camera while rendering AR content.

---

### 📱 Scene Navigation

Supports navigation between application scenes for a seamless user experience.

# ⚙️ Installation

## Prerequisites

- Unity 2022 LTS or newer
- Android Studio
- Android SDK
- AR Foundation Package
- Google ARCore XR Plugin
- ARCore Supported Android Device

---

## Clone Repository

```bash
git clone https://github.com/RiteshBadgujar/Unity-AR-Planet-Visualization.git
```

---

## Open Project

1. Open Unity Hub.
2. Select **Open Project**.
3. Choose the cloned folder.
4. Allow Unity to import all packages.

---

## Build & Run

```
File
    ↓
Build Settings
    ↓
Android
    ↓
Build And Run
```
